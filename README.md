# TOGUNパズル たたき台

## これは何か

テトリスのようにブロックが落ちてきて、横1列がぴったり埋まると消える
ゲームの「動く試作品（プロトタイプ）」です。

追加ルールとして、ブロックの1マスずつに T・O・G・U・N のどれかの文字が
ランダムで入っており、消えた列を左から読んだときに「TOGUN」と
連続で並んでいると、通常より高い得点が入ります。

## 中に入っているファイル

| ファイル | 役割 |
|---|---|
| `project.godot` | Godot（ゲームを作るための無料ソフト）に「これはゲームプロジェクトです」と伝える設定ファイル |
| `scenes/Main.tscn` | ゲーム画面の土台（今回は1枚だけのシンプル構成） |
| `scripts/Main.gd` | ゲームの中身（ブロックの動き・得点計算など）を書いたプログラム本体 |

## 今できること

- ブロックが自動で下に落ちる
- 矢印キーで左右移動・回転・下に早める
- スペースキーで一気に下まで落とす（ハードドロップ）
- 横1列が埋まると消えて得点が入る
- 消えた列に「TOGUN」の並びがあればボーナス得点
- 列を消すたびに、少しずつ落下速度が速くなる
- ブロックが積み上がって置けなくなったらゲームオーバー（Rキーで再挑戦）

## まだ仮のままの部分（次にClaude Codeで整える候補）

- ブロックの色は仮の2色のみ。文字ごとに色を変える、画像に差し替えるなどは未対応
- 回転のやり方が簡易版のため、一部のブロック形状で回転時の見た目がやや不自然になることがある
- 効果音・BGMはまだ無し
- スタート画面やタイトル画面は無く、起動していきなりゲームが始まる
- スマホでの指操作（タップ・スワイプ）にはまだ対応しておらず、現状はキーボード操作のみ

## Godotでの開き方（動作確認をする場合）

1. Godot（4系）を無料でダウンロードしてインストール
2. Godotを起動し、「インポート」からこのフォルダの `project.godot` を選ぶ
3. 開いたら再生ボタン（右上の三角マーク）を押すと、そのまま遊べます

## Claude Codeで進める際のヒント

このフォルダをそのままプロジェクトとして渡し、
「まずスマホのタップ操作に対応させたい」「ブロックの色を文字ごとに変えたい」
のように、直したい部分を1つずつ具体的に伝えると進めやすくなります。
